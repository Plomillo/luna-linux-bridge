# Louksna Web Local Bootstrap + Security (Linux-only)

Bootstrap local-first para preparar la integración de automatización web y seguridad de archivos con Louksna.

Componentes:
- Skyvern — agente web local/self-hosted.
- Stagehand — capa agéntica de control.
- Playwright — driver de navegador local (Chromium).
- ClamAV 1.5.4 — motor antimalware local Linux x86_64.
- Browserbase — no incluido; permanece como backend remoto opcional/fallback.

El perfil excluye plataformas de escritorio ajenas a Linux x86_64.
