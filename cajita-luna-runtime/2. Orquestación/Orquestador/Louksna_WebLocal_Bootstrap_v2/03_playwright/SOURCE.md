# Playwright

Official repository: https://github.com/microsoft/playwright
Official npm package: https://www.npmjs.com/package/playwright
Pinned version: 1.62.1

Playwright is the local browser driver. The bootstrap installs only Chromium to keep the local browser footprint minimal.

Install commands used by the bootstrap:
npm install --save playwright@1.62.1
npx playwright install chromium
