# Skyvern

Official repository: https://github.com/Skyvern-AI/skyvern
Official package index: https://pypi.org/project/skyvern/
Pinned version: 1.0.48

Verified official documentation states that Skyvern can run locally/self-hosted and supports a local server/UI path. It also documents AI browser actions, authentication, workflows and file downloading.

Install command used by the bootstrap:
pip install "skyvern[all]==1.0.48"
skyvern quickstart
