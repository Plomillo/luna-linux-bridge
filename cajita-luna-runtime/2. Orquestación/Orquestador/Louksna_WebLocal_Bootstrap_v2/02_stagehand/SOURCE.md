# Stagehand

Official repository: https://github.com/browserbase/stagehand
Official npm package: https://www.npmjs.com/package/@browserbasehq/stagehand
Pinned version: 4.0.2

Stagehand is the agentic browser-control layer. It can be used with a local Playwright browser and does not require Browserbase for local execution.

Install command used by the bootstrap:
npm install --save @browserbasehq/stagehand@4.0.2
