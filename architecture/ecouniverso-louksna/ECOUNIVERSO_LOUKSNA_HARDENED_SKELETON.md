## 10. Pipeline transaccional

Toda modificación consecuencial:

```text
REQUEST
→ INTENT
→ VALIDATION
→ EVIDENCE
→ PROPOSAL
→ PRE_COMMIT
→ CHECKPOINT
→ COMMIT
→ POST_VALIDATION
→ UPDATE
→ ACTIVE
```

Ante fallo:

```text
FAIL
→ ABORT
→ RESTORE_CHECKPOINT
→ VERIFY_RESTORATION
→ RECORD_FAILURE
→ AUDIT
```

## 11. G23 / G24

```text
G23 = INDEPENDENT_VALIDATION
G24 = CERTIFICATION

DECLARED
→ EVIDENCED
→ VALIDATED
→ INDEPENDENTLY_VALIDATED
→ CERTIFIED
→ ACTIVE
```

Prohibido:

```text
DECLARED_TO_CERTIFIED
EVIDENCED_TO_CERTIFIED
VALIDATED_TO_CERTIFIED_WITHOUT_G23
G24_WITHOUT_G23_PASS
SELF_CERTIFICATION
CERTIFICATION_PROPAGATION
ACTIVE_WITHOUT_COMPLETE_EVIDENCE_CHAIN
```
