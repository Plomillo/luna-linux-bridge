# Instrucciones fuente — Entrega 3

**Producto esperado:** base de datos organizada + informe breve (2 páginas). **Fecha:** 16 de noviembre de 2026.

En esta etapa deberán aplicar su instrumento a la muestra definida, revisar la calidad de las respuestas obtenidas y organizar toda la información recolectada en una base de datos. La realidad del trabajo de campo puede incluir respuestas incompletas, dificultades para completar la muestra e imprevistos. Lo importante es estructurar una base ordenada y utilizable, comprendiendo cómo una respuesta se transforma en un dato analizable y por qué ese orden condiciona el análisis posterior.

Base disponible para esta fabricación: exportación agregada de 39 respuestas por pregunta y seis preguntas. La naturaleza agregada debe declararse; no se presenta como microdatos individuales.
