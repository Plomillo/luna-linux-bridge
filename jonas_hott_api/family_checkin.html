Jonas · Confirmación familiar de saldo

Registro manual de un saldo que la persona ve en su propia cuenta. No consulta ninguna API de saldo del proveedor y no estima créditos a partir de tokens.

Pool único: family-shared · unidad: credits. Cada persona confirma el mismo saldo. Las respuestas nunca se suman. Si hay discrepancias, el sistema muestra CONFLICTING y no presenta un saldo confirmado.
