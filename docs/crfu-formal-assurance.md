## Mathematical work added in this candidate

- formal/cubical/CRFUUnivalenceBridge.agda states the Cubical univalence equivalence (A ≡ B) ≃ (A ≃ B), both inverse laws, the computation rule for transport along ua, and the identity-equivalence path rule.
- formal/crfu/CRFUClosureTheorems.agda adds sufficient-condition proofs complementing existing necessity proofs for plan, contract-composition, migration-coherence, recovery, and equivalence guards. It adds a versioned task decision model with separate safe-ready, hold-for-evidence, and forbidden-action denial cases, plus a task lifecycle relation with terminal-state no-outgoing-transition proofs. The previous TaskAndStateModel.agda remains byte-identical: its compiler warnings show that its false pattern shadows the Bool constructor, so the new proofs do not falsely attribute correct hold behavior to that legacy source.
- formal/crfu/ResourceBudgetRuntimeSemantics.agda defines the inclusive RAM/disk boundary semantics present in custoszv9/crfu/resources.py, including natural-number subtraction truncated at zero.
- formal/crfu/ResourceBudgetRuntimeSemanticsProofs.agda proves concrete boundary facts and explicitly demonstrates the equality-boundary disagreement with the historical strict ResourceBudgetModel.agda. No prior source file is silently rewritten.
- formal/crfu/ResourceBudgetDecisionSemantics.agda models the runtime budget decision order (invalid input → FAIL; incomplete/untrusted measurement → HOLD; measured resource violation → FAIL; satisfied constraints → PASS). It proves that PASS entails a valid budget, complete trusted measurements, and RAM, disk, and concurrency constraints; it also proves the converse for the declared guard model.
- formal/crfu/MissionQueueSemantics.agda formalizes the `ALLOWED` transition relation from custoszv9/crfu/event_queue.py and proves that COMPLETED, FAILED, BLOCKED, and DENIED have no outgoing transitions.
- formal/crfu/PlannerDecisionSemantics.agda models the runtime planner's decision order, proves all normalized admissibility guards are necessary and sufficient for `PLAN_VALIDATED`, and proves that a validated plan never implies execution authorization.
- formal/crfu/RecoveryDecisionSemantics.agda formalizes the exact normalized restoration guards and proves PASS requires byte identity, state identity, dependency identity, invariant proof, and a valid evidence journal.
- formal/crfu/EquivalenceDecisionSemantics.agda formalizes the normalized equivalence gates and proves that admissibility requires source and target identity, a bound specification, independent proof verification, an enumerated property set, and no forbidden property transport.
- formal/crfu/JournalChainSemantics.agda formalizes the normalized chain predicate from `verify_event_chain`: each event must link to the previous hash and its canonical event digest must match. It proves soundness (a valid journal implies all per-row checks pass), completeness for those normalized checks, and fail-closed rejection of a broken previous link or event digest.
- formal/crfu/GlobalGateTerminalModel.agda defines a ledger of exactly 24 ordered gate slots, and proves that terminal PASS implies every slot is PASS. Any FAIL or HOLD blocks terminal certification. The theorem is an aggregator guarantee; it does not claim that the actual global gate evidence has all been supplied.
